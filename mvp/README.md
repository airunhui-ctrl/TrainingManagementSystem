# 六边形培训管理系统 MVP

这是厦门六边形人才科技有限公司培训管理系统的零依赖浏览器演示版，用于先验证产品流程和视觉风格。正式工程与静态演示已分离：正式代码位于根目录 `frontend/`、`backend/`，本目录只保留静态预览和验证脚本。

## 启动

在项目根目录执行：

```powershell
node mvp/scripts/serve.mjs
```

然后打开 `http://localhost:4173`。

## 正式工程目录

- `frontend/client-uni`：uni-app + Vue 3 + TypeScript C 端，包含首页、详情、动态报名、业务、我的和登录页。
- `frontend/admin-react`：React + TypeScript 管理端，包含工作台、课程、报名模板、报名、订单支付和开票入口。
- `backend/api`：NestJS JWT 登录/校验示例，演示账号见该目录 README。
- `mvp/static-demo`：零依赖静态预览页面，不与正式工程混用。

也可以使用任意静态文件服务器。不要直接双击 `index.html`，因为 ES Module 在部分浏览器的 `file://` 协议下会被限制。

## 演示路径

### C 端小程序

1. 首页点击课程卡片的“查看详情”。
2. 点击“我要报名”。
3. 填写动态报名模板中的必填字段，可点击“添加报名人员”。
4. 查看人数优惠和总价，提交后进入模拟支付。
5. 选择微信/支付宝模拟支付，或选择线下支付进入待审核状态。
6. 在“业务”查看订单和开票申请，在“我的”查看用户摘要。

### 平台管理端

右上角切换到“平台管理端”，可查看：

- 工作台待办和课程统计
- 课程管理列表
- 报名模板卡片
- 报名数据
- 订单与线下审核
- 开票申请状态维护

## 当前限制

- 数据存储在浏览器内存，刷新页面会恢复为演示数据。
- 登录、真实微信/支付宝支付、短信、发票、文件上传和生产级权限暂为模拟或占位。
- 下一阶段可将 `mvp/static-demo/app.js` 中的数据访问替换为 `backend/api` 接口，并继续完善 `frontend/client-uni` 与 `frontend/admin-react`；JWT access/refresh token 的接口边界已预留。
